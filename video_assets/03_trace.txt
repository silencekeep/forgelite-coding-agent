Agent 的本地执行循环

[step 1]  模型选择 list_files
          → 找到 text_stats.py 与 tests/test_text_stats.py

[step 2]  模型选择 read_file
          → 对照实现与失败断言，定位 split(" ")

[step 3]  模型选择 replace_in_file
          → 改为默认 split()，它按任意空白拆分并忽略空项

[step 4]  模型选择 run_command
          → python -m unittest discover -s tests -v

每一项工具均由本机 Python 执行，输出作为 role=tool 回传给模型。
