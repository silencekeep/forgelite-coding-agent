# MP4 配音/讲解词（约 105 秒）

“大家好，我演示的是 ForgeLite，一个不用任何 agent 框架、只用 Python 标准库实现的本地编程智能体。

这次真实任务是修复一个文本统计函数。开始时两项测试失败：原实现只按单个空格分割，遇到换行、制表符和重复空格就会多计。

用户把任务交给 agent 后，模型并不直接访问我的机器。它先调用本地目录和读文件工具，比较实现和测试。接着它调用精确替换工具，把 split 空格改为 Python 的默认 split。然后它调用本地命令运行全部单元测试。三个测试全部通过后，agent 才报告成功。

模型负责选择下一步；控制循环、参数解析、工具执行、报错回传和最大回合停止条件，全部由本地代码实现。文件路径必须在指定工作区内，命令也有超时、输出截断和危险模式拦截。

为了防止上下文不断膨胀，我实现了历史压缩和 LRU Compact。近期读过的文件和测试结果优先保留为短摘要，但模型修改前仍会重新读取文件。最后，我提供 Low、Medium、High 三档思考强度，它们实际改变本地提示、默认回合数和上下文预算。

项目还包含九项不联网测试，以及一个从空目录创建完整小项目再运行测试的端到端控制循环测试。谢谢观看。”
