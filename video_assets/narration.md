# MP4 配音/讲解词（约 105 秒）

“大家好，我演示的是 ForgeLite，一个不用任何 agent 框架、只用 Python 标准库实现的本地编程智能体。

这次真实任务是从空目录一次性创建一个命令行待办项目。要求包括 add、list、done，JSON 持久化，错误退出码、完整测试和 README。

用户把任务交给 agent 后，模型并不直接访问我的机器。真实审计显示，它先确认工作区为空，再连续写入实现、测试和 README。第一次测试命令失败后，错误被作为 tool result 返回；模型自行更正命令，第二次运行五项测试全部通过，随后才给出最终总结。整个过程用了七个模型回合。

模型负责选择下一步；控制循环、参数解析、工具执行、报错回传和最大回合停止条件，全部由本地代码实现。文件路径必须在指定工作区内，命令也有超时、输出截断和危险模式拦截。

为了防止上下文不断膨胀，我实现了历史压缩和 LRU Compact。近期读过的文件和测试结果优先保留为短摘要，但模型修改前仍会重新读取文件。最后，我提供 Low、Medium、High 三档思考强度，它们实际改变本地提示、默认回合数和上下文预算。

我又独立进行了黑盒复验：添加、列出和完成任务正常，不存在的 ID 会返回退出码一。主项目目前有十五项不联网测试，另有脚本化端到端控制循环测试。谢谢观看。”
