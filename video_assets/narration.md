# MP4 配音/讲解词（工作过程为主，神经语音约 105 秒）

“大家好，我演示的是 ForgeLite，一个不用 Agent 框架、用 Python 标准库实现的本地编程智能体。

我把 High 档位下的真实任务交给它：从空目录创建命令行待办项目，实现三个子命令、JSON 持久化、测试和 README。

提交后，浅色工作台流式显示 ReAct：Reason 是规划状态，Act 是工具调用，Observe 是本地结果。界面不展示思维链，只展示控制循环中可审计的事件。

第一轮，模型确认工作区为空，随后写入程序、测试和 README。所有操作都由本地工具在固定工作区执行。

第五轮测试命令第一次失败。红色 Observe 连同调用编号写回历史，没有被误报成成功。第六轮模型更正命令，五项测试全部通过。第七轮没有新工具调用，模型总结结果，循环正常停止。

底层链路是模型请求、工具调用、本地执行、结果回传，再进入下一轮。历史过长时，程序按完整工具调用组压缩；LRU Compact 优先保留最近文件和命令。Low、Medium、High 会真实改变规划提示、回合数和上下文预算。

最后我独立复验了主要命令和错误输入。这个视频展示的不是一次性生成代码，而是能观察、行动、从失败中修正，并用测试证明完成的编程智能体。谢谢观看。”
