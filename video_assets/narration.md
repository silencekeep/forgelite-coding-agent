# MP4 配音/讲解词（工作过程为主，约 105 秒）

“大家好，我演示的是 ForgeLite，一个不用 Agent 框架、只用 Python 标准库实现的本地编程智能体。

我把 High 思考档位下的真实任务交给它：从空目录创建命令行待办项目，实现 add、list、done、JSON 持久化、错误退出码、完整测试和 README，全程不暂停。

提交后，浅色工作台开始流式显示 ReAct 过程。Reason 表示模型正在规划下一步；Act 是经过本地校验的工具调用；Observe 是工具返回的成功或失败结果。这里不会展示或伪造模型隐藏思维链，只展示我自己的控制循环能够审计的事件。

第一轮，模型列出文件并确认工作区为空。接下来它依次写入 todo_app.py、测试和 README。所有文件操作都由我的 Python 工具在固定工作区执行，模型本身不能直接访问电脑。

第五轮运行测试时，命令第一次失败。红色 Observe 被连同 tool call ID 写回对话历史，程序没有崩溃，也没有把失败误报成成功。第六轮模型根据观察结果更正命令，再次运行后五项测试全部通过。第七轮没有新的工具调用，模型给出最终交付总结，控制循环正常停止。

底层链路是模型请求、tool calls、本地执行、tool result，再回到下一次模型请求。历史过长时，我会按完整工具调用组压缩旧消息，并用 LRU Compact 优先保留最近文件和命令摘要。Low、Medium、High 会真实改变规划提示、最大回合数和上下文预算。

最后我独立复验了 add、list、done 和错误 ID，结果正确。这个视频展示的不是一次性生成代码，而是能观察、行动、从失败中修正并用测试证明完成的编程智能体。谢谢观看。”
